# Проект dice-simulator

Dice Simulator - проект, основной функционал которого заключается в симуляции бросков игральных костей (дайсов).
Данный функционал реализуется с помощью API, WebUI и CLI-утилиты.

## Технический стек
- backend: Python/FastAPI, рабочая директория `backend/` 
- frontend: Vite+Vue & TypeScript, рабочая директория `frontend/`
- CLI: Python, рабочая директория `cli/`
- дополнительные технологии: Docker для контейнеризации

Остальные каталоги являются инфраструктурными.

## Источники истины
- Требования: `openspec/`. Не выдумывать поведение, которого нет в спеке.
- Работа: Beads (`bd ready`, `bd show <id>`).
- Контракт API: `backend/openapi.json` при наличии.

## Правила
- Одна bounded-задача за раз. Не "улучшать проект вообще".
- Перед изменением кода: прочитать релевантный spec/bead.
- Проверка: `uv run pytest` в `backend/`, `npm test` в `frontend/`.
- Не трогать `.env`, секреты, `~/`, другие репозитории.
- Завершение = зелёные проверки + обновлённый статус задачи, а не сообщение "готово".
