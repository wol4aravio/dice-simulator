# Dice Simulator

Данный проект выполняется в качестве реализации процесса обучения использования агентов для цикла AI PDLC.
Сам проект представляет собой симулятор броской игральных костей из набора DnD (например, 1d3, 1d6) с модификаторами.

# Требованию к функционалу проекта

## Backend

Для backend должен быть создан API-сервис со следующими endpoint:
- `/health` - базовый healthcheck проекта
- `/roll` - выполнить бросок определённой конфигурации дайсов

Под капотом у сервиса обязательно должны быть:
- модуль валидации корректности ответа

## Frontend

Сервис будет дистрибуцироваться в нескольких форматах, один из которого - это небольшой Web UI.

## CLI

Кроме UI, будет представлена cli-утилита, к которой можно будет обращаться из терминала.
